# 品牌作品图片

将图片放入品牌下的分类文件夹，支持 JPG、JPEG、PNG、WebP、AVIF、GIF。

```text
public/images/
  HURMEVKOR/
    主图/
    详情/
    场景/
  DR.WOSSEN/
    主图/
    详情/
    场景/
  INSDCDOCTOR/
    主图/
    详情/
    场景/
```

品牌目录也支持中文名称：华美科、沃森博士、因斯博士。
分类目录可以包含子文件夹。图片按文件名自然排序，建议命名为 01.jpg、02.jpg。

运行 npm run dev 时，打开的品牌弹窗每 3 秒读取最新目录。
新增、删除、替换图片不需要修改代码，也无需重启开发服务。
没有实际作品的目录显示“此分类暂无图片”，不会使用示例图片冒充作品。

静态发布：新增图片后运行 npm run build，将 dist 整体重新部署。
纯静态服务器不能直接扫描本机文件夹，仅上传图片但不更新图片清单不会自动显示。
使用 npm run preview 前也应重新构建，以确保 dist 的图片文件同步。
