# Personal Portfolio

React + Vite single-page designer portfolio.

## Development

```sh
npm install
npm run dev
```

## Verification

```sh
npm run build
node tests/smoke.mjs
```

The smoke test expects the development server on port 5173 and a local Google Chrome installation.

## Content

- `src/data.js`: personal profile, contact information and project data.
- `src/main.jsx`: page sections and interactions.
- `src/styles.css`: visual system and responsive layouts.
- `public/images/`: replaceable local image assets.
- `public/videos/hero.mp4`: replaceable background video.

Resume details have not been supplied. Names, biography and project entries are placeholders; statistics are not fabricated. Enter an email or WeChat ID in `src/data.js` to enable contact actions.
